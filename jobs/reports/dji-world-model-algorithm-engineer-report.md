# DJI 世界模型算法工程师（上海）岗位工作报告

Source JD: [DJI 大疆 - 世界模型算法工程师（上海）](../jd/dji-大疆-世界模型算法工程师-上海.md)

Application status: applied, 2026-06-28

## 1. 岗位核心判断

这个岗位不是单纯的“视频生成”或“3D 重建”岗位，而是飞行场景下的可控生成式数字孪生与训练数据闭环岗位。JD 中的技术栈从真实飞行片段出发，经过 3D/4D 重建、新视角合成、可控生成、场景编辑、log2world、仿真平台集成，最终服务于数据合成、强化学习训练和具身智能闭环。

一句话概括：把真实飞行数据变成可重放、可编辑、可生成、可训练的世界模型底座。

对你的匹配重点应放在三条线上：

1. 3DGS/4DGS、NeRF、隐式神经表示与新视角合成。
2. 重建模型与生成模型的耦合：用重建保证几何，用生成提升真实感和长尾扩展。
3. 面向训练闭环的工程意识：数据处理、评测、仿真平台接入、模型迭代。

## 2. JD 提到的工作模块拆解

### 2.1 可控生成式数字孪生

JD 中“可控生成式数字孪生”是总目标。它强调的不只是视觉效果，而是可用于训练循环的数字环境。

关键含义：

- 可生成：能够从真实数据或条件输入生成新的场景、轨迹、视角或事件。
- 可分支：同一个真实片段可以被编辑出不同环境、目标、运动路径或危险场景。
- 可重放：生成结果需要能在仿真或训练平台里复现，而不是一次性的视觉样例。
- 可控：生成过程要受相机轨迹、物体位置、场景布局、天气光照、任务条件等因素约束。

对应技术问题：

- 如何从真实飞行片段构建几何一致的 3D/4D 表示。
- 如何让生成模型遵守场景几何、相机运动和任务约束。
- 如何把生成结果接入仿真、评测和训练链路。

你可对应的经历：

- 吉利实习中的街景大幅度新视角外推，与“重建-生成耦合”直接相关。
- AI-assisted photography 中的 Marble/SHARP/UE/神经渲染流程，可作为“从图像到可控三维空间再到生成增强”的原型案例。
- ECCV 2026 3DGS 工作可证明你熟悉 3DGS 表示及其层级化、区域化、码流化处理。

### 2.2 大规模 3D/4D 场景重建

JD 职责第一条是“基于多视图/时序传感器的大规模 3D/4D 场景重建与新视角合成算法研发”。这里的重点是飞行场景下的时空重建。

3D 重建关注静态场景或短时间内近似静态的结构；4D 重建进一步包含时间维度，需要处理动态物体、相机运动、遮挡、时序一致性和动态场景表示。

可能涉及的技术路线：

- SfM/MVS 或 SLAM 初始化相机位姿和稀疏结构。
- NeRF/3DGS 用于连续视角渲染。
- 4DGS、dynamic NeRF、deformable field、scene flow 等处理动态场景。
- 多传感器输入可能包括 RGB、多视图视频、IMU、深度、LiDAR 或飞行日志。
- 大规模场景需要分块、层级化、流式加载、增量更新和高效渲染。

岗位可能关注的难点：

- 飞行相机轨迹变化大，视角跨度大，遮挡和尺度变化明显。
- 动态目标和背景同时存在，静态重建假设容易失效。
- 训练数据量很大，不能只依赖小规模 per-scene optimization。
- 结果最终要服务训练闭环，因此几何一致性、渲染速度、可编辑性都重要。

你可对应的经历：

- 3DGS Object Scalability：对 3DGS 层级重组、ROI 区域划分、渐进式表示和流式传输有直接经验。
- NeRI：把 LiDAR 序列映射为 range image sequence 并用时空条件网络表示，能支撑你讲“时序三维数据表示”。
- 吉利实习：UniSplat 前馈街景重建与大幅度外推，是面向高效重建和新视角合成的直接经历。

### 2.3 新视角合成与大幅度外推

新视角合成是这个岗位和你当前实习最直接的交集。DJI 场景中的新视角合成，不只是补几帧好看的图，而是为飞行训练提供新的观察角度和可能轨迹。

技术目标：

- 从已有飞行片段生成未观测或少观测视角。
- 保持相机运动、几何结构、尺度关系和动态物体一致。
- 在大幅度视角变化下仍保持可用画质。
- 为长尾场景仿真提供可控视角扩展。

典型方法关系：

- 前馈重建模型：速度快，适合规模化处理，但在大幅外推时可能渲染质量下降。
- 生成模型：真实感和补全能力强，但容易破坏几何一致性。
- 重建-生成耦合：用几何约束生成结果，用生成先验改进重建渲染质量。

你当前最适合讲的表达：

“我在吉利实习中聚焦街景大幅度新视角外推，探索 UniSplat 前馈重建模型与 VISTA 生成模型的双向增强：一方面用前馈重建约束生成模型的几何一致性，另一方面利用生成先验改进前馈重建方法的渲染质量损失。”

注意事项：

- 不要把“调研世界模型”说成已经完整做了世界模型系统。
- 要把主线放在“大幅度新视角外推”和“重建-生成耦合”，这是最扎实的部分。

### 2.4 可控视频生成与场景编辑

JD 第二条要求“可控视频生成与场景编辑算法，支撑长尾场景仿真与真实数据的可控扩展”。这里的关键词是“可控”和“长尾”。

可控视频生成可能包括：

- 给定相机轨迹生成飞行视频。
- 给定场景布局、目标位置、天气光照或动作条件生成视频。
- 保持多帧时序一致性、几何一致性和物体身份一致性。
- 生成极端或低频事件，用于覆盖真实数据中不足的长尾分布。

场景编辑可能包括：

- 插入、删除或移动物体。
- 修改纹理、光照、天气、时间段。
- 改变相机轨迹或目标行为。
- 将真实场景重建结果变成可编辑资产。

你可对应的经历：

- AI-assisted photography 的虚拟摄影棚流程：场景 3DGS 与人物 3DGS 组合导入 UE，实现可控拍摄和神经渲染增强。
- Spatial Reframing：输入图像外扩、SHARP 3DGS 重建、相机姿态变换、新视角渲染与生成先验修复，本质上是一个小尺度的“可控视角编辑”原型。
- 吉利实习中的 VISTA 相关调研/实验，可对应生成模型和新视角生成。

可以补充准备的问题：

- 你具体用过哪些生成模型或 diffusion/video generation 框架。
- 你的实验是否有定量评测，使用了哪些指标。
- 生成先验如何进入重建训练：作为监督图像、perceptual loss、mask confidence，还是几何/光度混合约束。

### 2.5 仿真平台与训练链路集成

JD 第三条是“仿真平台与训练链路的算法侧集成，支撑数据合成与强化学习训练闭环”。这部分更偏系统闭环，不是只看算法 demo。

可能工作内容：

- 将重建/生成结果转换为仿真平台可使用的资产。
- 把生成数据接入训练数据管线。
- 设计数据质量过滤、标签继承、传感器对齐和评测标准。
- 支持策略模型或感知模型在仿真环境中训练、回放和评估。
- 从模型失败 case 反向生成更有价值的数据，形成数据飞轮。

log2world 的含义：

- log 指真实采集的飞行日志或传感器记录。
- world 指可交互、可重放、可编辑的世界环境。
- log2world 就是把真实记录转化为可用于仿真和训练的数字世界。

你目前的可讲证据：

- AI-assisted photography 中已有“资产导入 UE、沉浸式漫游、虚拟拍摄”的平台接入经验，但这更像原型，不应夸大为训练闭环。
- 吉利世界模型项目中参与相关技术路线调研，可支撑你理解 log2world 和 driving world model 的系统目标。
- 3DGS 压缩工作中的渐进式表示、流式传输、区域质量控制，可与大规模仿真资产管理建立联系。

明显短板：

- 暂时没有明确的强化学习训练闭环经历。
- 暂时没有无人机或机器人真实 log2world 落地经历。
- 如果面试问 sim-to-real 或 RL，需要以学习能力和系统理解回答，不要硬编项目经验。

### 2.6 前沿跟踪与业务落地

JD 第四条要求跟进世界模型、神经渲染、生成式仿真方向进展并落地。这里不只是“读论文”，而是要求能把前沿方法拆成可复现、可评测、可迁移的工程方案。

建议重点准备的方向：

- 3D/4D Gaussian Splatting：动态场景表示、实时渲染、大规模场景管理。
- Driving/Embodied World Model：VISTA、GAIA、DriveDreamer、WorldDreamer、Cosmos、Genie 等系统的核心思想。
- Reconstruction-generation coupling：如何把重建和生成从串联变成互相约束。
- Controllable video generation：相机轨迹控制、几何条件、深度/法线/光流/pose conditioning。
- Evaluation：几何一致性、时序一致性、感知质量、任务有效性，而不只是 PSNR/LPIPS。

你已有基础：

- 吉利项目中的世界模型路线调研。
- 新视角合成和生成先验结合的正在进行工作。
- 多篇三维数据压缩和神经表示论文经历。

推荐讲法：

“我目前直接做训练闭环的经验还不算完整，但我理解 DJI 这个岗位的关键不是生成好看的视频，而是把真实飞行数据变成可控、可回放、可扩展的数据引擎。我的优势在三维表示、新视角生成和重建-生成耦合，接下来需要更快补齐仿真平台接入、数据质量过滤和 RL/训练闭环侧的工程经验。”

## 7. 风险点与补强建议

### 风险点 1：RL / sim-to-real 经历不足

处理方式：

- 不要声称已经做过完整强化学习闭环。
- 强调你理解该岗位的闭环目标，已有三维表示和生成式仿真上游能力。
- 准备一个“如何接入训练闭环”的方案草图：数据生成、质量过滤、标签继承、训练、评测、失败 case 反哺。

### 风险点 2：视频生成经历可能不够直接

处理方式：

- 把 VISTA 相关工作定位为生成模型和新视角合成方向。
- 把 AI 摄影中的生成先验修复作为“局部生成增强”案例。
- 补充阅读可控视频生成和 diffusion conditioning 方法。

### 风险点 3：无人机飞行数据经验不足

处理方式：

- 用自动驾驶街景和飞行场景的共性做桥接：移动相机、多视角时序、动态场景、长尾事件、仿真训练。
- 主动承认传感器和运动模式不同，但强调三维重建、新视角外推和生成式仿真的方法论可迁移。
